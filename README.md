# CrudEstoque

Sistema CRUD para gerenciamento de estoque.

## Funcionalidades

* Cadastrar produtos
* Listar produtos
* Editar produtos
* Excluir produtos

## Como executar

Clone o projeto:

```bash
git clone https://github.com/williamsneto-cell/CrudEstoque.git
```

Entre na pasta:

```bash
cd CrudEstoque
```

Execute o projeto.
